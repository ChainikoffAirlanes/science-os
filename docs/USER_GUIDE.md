# Краткое руководство

1. Создайте аккаунт с email и паролем. По решению владельца вход доступен сразу, без письма подтверждения. Вход и хранение пароля используют Supabase Auth. Почтовое восстановление не включено; если вы ещё вошли в аккаунт, измените пароль в настройках. При потере доступа обратитесь к администратору платформы.
2. Нажмите «Создать проект». Заполните тему, область, гипотезу, цели и сроки. Каждый научный раздел можно редактировать отдельно. Для заголовков используйте `#` или `##`, для списка — `-`.
3. В «Экспериментах» создайте опыт. Добавьте параметры: число, текст, дата/время или логическое значение. Единицы могут быть произвольными. Для boolean вводите `true/false` или `да/нет`.
4. Добавьте наблюдение. Tab переводит фокус дальше; Enter сохраняет, Escape отменяет ввод. Выход из ячейки тоже сохраняет. Не закрывайте страницу при сохранении или сетевой ошибке. При конфликте выберите серверное значение либо явно повторите своё изменение.
5. Для CSV/XLSX выберите файл, сопоставьте столбцы и проверьте предпросмотр. Импорт добавляет данные одной транзакцией и не заменяет существующие строки. Максимум — 2 000 строк и 10 МБ за один импорт.
6. В аналитике выберите эксперименты, X и числовые Y, диапазон и тип графика. Для сравнения X должен быть уникальным внутри каждого опыта, названия параметров и единицы должны совпадать. Щёлкните легенду, чтобы скрыть серию. Конфигурацию можно сохранить, график — скачать.
7. Владелец приглашает участников по ссылке и выбирает редактора или наблюдателя. Приглашение по умолчанию одноразовое и действует семь дней. Наблюдатель не может редактировать. Владелец остаётся в проекте постоянно.
8. Во «Файлах» загрузите документы или изображения до 10 МБ. Используйте папки и меню файла. Ссылки приложения требуют доступа к проекту. Чтобы удалить проект, сначала удалите все его файлы.
9. В задачах создайте карточку, назначьте участника и срок. Меняйте статус через форму и обсуждайте работу в комментариях.
10. В отчёте выберите разделы, таблицы, сохранённые графики и авторов. Откройте настоящий PDF или скачайте его. Предпросмотр HTML показывает первые 20 строк каждой таблицы; PDF содержит все строки и переносит их по страницам.
11. Для публикации владелец выбирает разделы и аудиторию, проверяет предпросмотр и подтверждает публикацию. Файлы и закрытые поля проекта не открываются автоматически.
12. Преподаватель создаёт исследовательскую возможность; ученики отправляют заявки. Преподаватель принимает или отклоняет их. Роль преподавателя выдаёт администратор после проверки.
