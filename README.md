# Science OS

Русскоязычное исследовательское пространство для учеников, преподавателей и команд. React, TypeScript, Vite, Supabase, GitHub Pages. Без искусственного интеллекта и платных API.

## Запуск

Требуется Node.js 24 LTS. Установите зависимости: `npm ci`. Скопируйте `.env.example` в `.env.local` и укажите URL Supabase и **клиентский publishable key**. Выполните `npm run dev`.

Примените все SQL-файлы из `supabase/migrations/` по порядку к новому проекту Supabase. Они создают таблицы, RLS, проверяемые RPC, приватные хранилища и Realtime policies. Не запускайте начальную миграцию в неизвестной существующей базе.

По решению владельца текущая установка использует простую регистрацию по email и паролю **без подтверждения письмом**. Восстановление по почте выключено; пароль можно изменить внутри аккаунта. Код PKCE и почтового восстановления сохранён для будущего подключения SMTP; после настройки почты включите `VITE_EMAIL_DELIVERY_ENABLED=true` и подтверждение email в Supabase.

Без настроенного Supabase экран входа честно сообщает, что облако ещё не подключено. Демо-аккаунтов и искусственных исследований в production нет.

## Проверки

- `npm run typecheck` — строгая проверка TypeScript.
- `npm run lint` — ESLint.
- `npm test` — вычисления, валидация, CSV/XLSX и реальное выполнение SQL в изолированном PGlite PostgreSQL.
- `npm run test:e2e` — браузерные сценарии; конкретный режим данных описан в файлах тестов.
- `npm run build` — production-сборка в `dist/`.

## Возможности

Проекты и научные разделы, эксперименты с пользовательскими параметрами, атомарное редактирование ячеек, CSV/XLSX, четыре типа графиков и выборочная статистика, сравнение опытов, приватные файлы и папки, задачи и комментарии, приглашения и роли, Realtime и Presence, отчёты PDF с кириллицей, безопасные снимки публикаций, предложения преподавателей и заявки, уведомления и темы оформления.

Фактическая полнота реализации, выполненные проверки и ограничения фиксируются в PROGRESS.md и RELEASE_REPORT.md. Наличие кода не означает, что облачная функция проверена.
